# AI Prompts – Automation and Debugging

## Entry 1 – Automation Planning

### Prompt

For the Practice Software Testing Toolshop assessment, help plan the Playwright automation structure.

Requirements:
- JavaScript
- Playwright
- Prism-style maintainable structure
- Separate UI and API automation
- Page objects for UI
- Reusable API helpers
- Reusable utilities
- Smoke and Regression tags
- HTML execution report
- Screenshots and trace on failures
- Environment-based configuration

Do not create application-specific test code yet.
Do not invent locators or API behavior.
Focus only on the automation structure.

### AI Response Summary

The automation should separate UI tests, API tests, page objects, API helpers, and reusable utilities.

Playwright configuration should provide environment-based URLs, reporting, screenshots on failure, and trace collection for failures.

Smoke and Regression tags should allow targeted execution.

### Debugging Outcome

No debugging was performed during this planning stage.

The proposed structure will be validated by creating the project incrementally and executing tests after implementation.
